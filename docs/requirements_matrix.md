# Requirements Matrix

> Put this file at `docs/requirements_matrix.md`.
> Built from: spec = `backend_requirements_ingestion_to_compare.md` (section 24 acceptance criteria + the requirement
> text in sections 2-23), `AGENTS.md` (sections 3-23), and the participant bundle README.
>
> Editing rules (see docs/PHASE_PROTOCOL.md section 2): never delete or reword a seed row; add rows freely; edit only
> Status / Evidence / Notes. `WAIVED` is human-only. `PASS` needs executable evidence
> (`tests/...::test_x` carrying `@pytest.mark.req("ID")`, or an existing report path for audit rows).
>
> Phase = phase that must make the row PASS. Order: 0, 1, 2, 3, 4, 5, 6A, 6B, 7, F.
> Verify: U = unit test, I = integration test, M = metamorphic test, R = reliability test, A = audit report/grep.
